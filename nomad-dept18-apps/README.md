# nomad-dept18-apps

NOMAD search page "Dept. 18 lab data" (Apps menu, category "FZU Dept. 18") for the entries of the Dept. 18 plugins:
nomad-dsc-trios, nomad-thermomech, nomad-walterbai, nomad-linseis, nomad-apt, nomad-infratec.

The page only lists entries of those schemas (locked filter) and has one filter menu per instrument.
Schema class paths are in `src/nomad_dept18_apps/apps/__init__.py` (`SCHEMAS`).
